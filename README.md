# E-Commerce Product Gallery 🛍️

## About the Project
This project is a simple and responsive E-Commerce Product Gallery created using HTML and CSS. It displays different products with images, names, descriptions, and prices in an attractive layout.

## Features
- Displays 6 different products.
- Modern and clean design.
- Responsive product grid layout.
- Hover animations on product cards.
- Product images and descriptions.
- Attractive product prices.
- Styled Add to Cart buttons.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- CSS Transitions
- CSS Hover Effects

## Products Included
1. Sports Shoes
2. Headphones
3. Smart Watch
4. Modern Chair
5. Fitness Watch
6. Digital Camera

## Project Files
- `Task1.html` – Contains the HTML structure.
- `Task1.css` – Contains the styling and design.
- `README.md` – Contains project information.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `Task1.html` in your web browser.
4. View the E-Commerce Product Gallery.
