# E-Commerce Product Gallery 🛍️

## About the Project
This is a simple and responsive E-Commerce Product Gallery created using HTML and CSS. It displays different products in an attractive grid layout with product images, names, descriptions, and prices.

## Features
- Displays 6 different products.
- Clean and modern user interface.
- Responsive product grid layout.
- Hover animations on product cards.
- Product images with descriptions and prices.
- Styled Add to Cart buttons.
- Simple and user-friendly design.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- CSS Transitions and Hover Effects

## Project Structure
```text
E-Commerce-Product-Gallery/
```

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the product gallery.

## Project Preview
The project displays six products, including sports shoes, headphones, smart watches, a modern chair, and a digital camera.
